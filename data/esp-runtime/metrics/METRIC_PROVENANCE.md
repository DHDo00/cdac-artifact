# METRIC_PROVENANCE.md — 数字口径核验说明（第 35 轮，2026-10-28/29）

数据核验，不构成新增运行实验。逐项数字的来源/分母/统计定义见
`METRIC_PROVENANCE.csv`（24 行：12 项任务书数字 + 支撑/口径区分/源码审计行）。
本节记录核验方法、重算结果与必须保留的口径边界。

## 1. 方法
1. 从论文基线（33 轮 02_paper_revision/{conference_101719.tex, evaluation_completed.tex,
   unified_results_table.tex}）定位每项数字的表述；
2. 回溯到对应轮次的冻结协议、原始 CSV/ledger、统计脚本与完成报告；
3. 对可重算项用原始数据独立重算并与论文汇报值比对；
4. 结果一致→保留原数据；不一致→保留原数据并列差异（本轮未发现数值不一致，
   仅发现两处同数字不同口径的并存历史，见 §4）。

## 3. 逐项口径说明（任务书硬性要求）
- **40/40、120/120**：论文正式分母来自 batch3d 两 boot 同制品报告
  （DP 4/301 + S10 8/701），上游=DP 稳定性报告与 S10 正式 4×40 报告。
  40/40=目标真实拒止/目标尝试；120/120=允许控制（不是 120 次目标）。
- **40/40(无关 Provider)**：端点分离控制（S10 规则 active 时 4/301 通用控制
  40/40 join 预期端点且成功、0/40 误拒）。与两路由的 40/40 目标拒止是不同分母，
  不合并。
- **3/3**：任务书列表中的 “3/3” 在论文里是**多条不同路线的小样本**（ESP 5/401 写、
  MediaProvider 6/501 写、txn23 redacted 读、txn14/txn23 跨入口、30 轮别名各腿）。
  CSV 按路线分列；跨轮复现（如 ESP 在 06/09/12/16）不累加为总样本量。
- **10/10**：论文正面 “10/10” = RQ3 转发最终跳见证（batch2ac，1 个 runtime
  session 内 10 次重复请求，不是 10 个 boot）。DP 正式报告里另有 “撤规后 10/10
  目标写恢复” 的同数字异口径，CSV 分列，不得混用。
- **61/61**：规则规模正确性步 = 17 真实拒止 + 44 允许/健康/撤规；**不是 61 次
  拒止**；**不是实验分母**。来源=21 轮 correctness_results.csv(56)+b2_health(5)。
- **160/160**：26 轮并发下的逐请求“主体-对象-结果”唯一归属正确率（40 真实拒止
  +120 允许、0 串扰），不是 160 次真实执法；与旧 MP 重建 160/160(F005) 不同口径。
  240 请求对=重叠佐证，不是 240 次独立试验。
- **24+60**：24=两 boot 合计异常触发（12/boot）；60=两 boot 合计恢复请求
  （30/boot）。两组语义不同，不合并为 84。
- **128 条规则**：21 轮最大实测活跃规则数（N∈{0,1,8,32,128}），不是实验分母；
  8192 容量与 64 fd 审计缓存=源码审计，未经运行验证。
- **0.252 ms**：测量区间=open 调用前即刻起至返回 FD/期望拒止止；状态=P1(1 条
  不匹配规则) − P0(同补丁空策略引用)；基线=P0，**不是 pristine Android**；统计
  定义=40 个会话内配对**区组中位数差**的中位数（非请求级、非 boot 级均值）。
  源文件同时给出块均值差(mean of block-means)=−27629.1 ns，论文只引用区组中位数
  差中位数=+0.252 ms，口径一致；**不能凭 0.252 ms 推断为 native overhead**
  （其 CI [-0.184,0.925] ms 跨零，未分辨正增量）。
- **+2.72/+2.26 ms**：原统计定义=4 对 boot 的 **per-boot 中位数差(type-7)的均值**，
  不是合并 800 请求的总体中位数差；不得改称“合并请求总体中位数”。S2 与 S3 在该
  精度未分辨；仅 ESP 制品/负载；4 对无正式置信区间。

## 4. 同数字不同口径/历史更正（保留原数据，不静默修改）
1. **10/10**：论文正面=batch2ac 转发最终跳见证；DP 正式报告=撤规后健康。两者
   并存、分列（CSV 两行）。
2. **160/160**：26 轮并发归属 vs 旧 MP 重建(F005)。分列，不合并。
3. **24 触发口径**：24 轮自身报告 “12 异常后 30 恢复” 为单 boot 口径；28 轮
   “24+60” 为两 boot 合计；29b 勘误统一为 “24(12/boot)+60(30/boot)”。无矛盾，
   仅单/双 boot 口径，保留历史文件原样。
4. **R1 归属更正（历史差异，不属本表数字）**：原 29 轮曾把 25 轮 txn23 B→X 拒止
   当作 R1 主体反转证据；29b 勘误更正为相关机制证据、R1=MISSING。历史 29 轮目录
   未改，勘误登记在 29b ERRATA_AND_PROVENANCE.md。本轮不做“补造”，只运行原路线。
5. **“61 项正确性=61 次拒止”**：错误口径（真实=17 拒止+44 允许），已在
   CLAIM_EVIDENCE_MAP“收紧项”明确禁止，本表沿用。
